Cutout extraction

cutana.cutout_extraction ¶

Vectorized cutout extraction utilities for Cutana.

This module provides optimized, vectorized functions for extracting multiple cutouts simultaneously from FITS files using batch processing of coordinates and bounds calculations.

extract_cutouts_vectorized_from_extension(hdu, wcs_obj, ra_array, dec_array, size_pixels_array, source_ids=None, padding_factor=1.0, config=None) ¶

Extract multiple cutouts from a single FITS extension using vectorized operations.

This function implements the vectorized approach: Step 1: Build source batch arrays (ra, dec, size_pixels) Step 2: Use vectorized SkyCoord for coordinate transformation Step 3: Vectorized bound computation Step 4: Broadcasted array operations for cutout extraction Step 5: Vectorized padding

 required
size_pixels_array ndarray

Array of cutout sizes in pixels

 required

Optional list of source IDs for logging

 None

Factor to scale the extraction area (1.0 = no padding)

 1.0

Tuple[List[Optional[ndarray]], ndarray, ndarray, ndarray]
