Performance profiler

cutana.performance_profiler ¶

Performance profiler for Cutana cutout processing.

This module provides a lightweight profiler to track runtime of different processing steps within the cutout creation pipeline. Each cutout process instance should have one profiler to monitor performance.

PerformanceProfiler(process_id=None, timing_function=time.perf_counter) ¶

Lightweight performance profiler for tracking runtime of processing steps.

Each cutout process should have one instance of this profiler to track: - FITS file loading time - Cutout extraction time - Image processing time - Output writing time

Initialize performance profiler.

Parameters:
